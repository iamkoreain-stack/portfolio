Silicon Verification Status

오실로스코프·breadboard·STM32 DAC·차동 amplifier로 측정 환경을 직접 구성해 칩 동작을 디버깅했다. 초기에는 일부 동작을 확인했으나 검증 도중 칩이 더 이상 동작하지 않았고, 고장 원인은 확정하지 못했다.

따라서 SNDR·ENOB 등 위 표의 수치는 post-layout 시뮬레이션 결과이며, 실리콘 최종 성능 실측은 완료하지 못했다.

Architecture Decision — CDAC Floorplan

CDAC layout 후보 3종(interleaved / grouped / grouped-and-folded)을 검토한 뒤, capacitor switch 배치를 바꿔 block 간 routing capacitance를 줄이는 방향으로 floorplan을 수정했다.

ObservationCapacitor switch가 capacitor array와 떨어져 있어 block 간 routing capacitance가 발생
↓
Candidate ReviewCDAC layout 구조 3종 비교 — Interleaved / Grouped / Grouped-and-folded
↓
DecisionCapacitor switch를 capacitor array에 인접하도록 재배치
↓
ResultBlock 간 routing capacitance 저감 (졸업논문 포스터 기준 floorplan 개선)

Circuit Implementation

일반적인 asynchronous SAR ADC 구조를 기준으로 구성한 블록 다이어그램이다. 실제 회로도가 아닌 아키텍처 설명용 다이어그램.

파란 경로 = analog signal · 초록 경로 = digital control / decision

Conversion Timing

Asynchronous SAR 구조이므로 bit decision마다 self-timed으로 진행되며 고정 clock에 종속되지 않는다. 아래는 개념적 conversion timing이다.

CONV → SAMPLE(track/hold) → 10× async bit decision → EOC
